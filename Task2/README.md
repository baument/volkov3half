# Задание №2. Вариант 5. Отдел кадров

Учебная программа на C++ с использованием наследования и полиморфизма.

## Структура

- Library — классы предметной области.
- ConsoleApp — консольная программа с меню.
- Tests — автоматические проверки.

## Классы

- Person — человек с ФИО и уникальным ID.
- Worker — общие данные сотрудника.
- WorkingWorker — работающий сотрудник.
- VacationWorker — сотрудник в очередном отпуске.
- ChildCareWorker — сотрудник в отпуске по уходу за ребёнком.
- Position — должность.
- Department — отдел кадров и поиск сотрудников.

## Возможности

- Просмотр всех сотрудников.
- Поиск по ФИО, должности и ставке.
- Поиск сотрудников с детьми.
- Поиск пенсионеров и сотрудников с инвалидностью.
- Поиск сотрудников по статусу отпуска.
- Просмотр информации о должностях.
- Просмотр предыдущих мест работы.
- Проверка повторного добавления сотрудника.

## Сборка

Из корня репозитория:

    cmake -S Task2 -B Task2/build
    cmake --build Task2/build

## Запуск

На macOS или Linux:

    ./Task2/build/ConsoleApp

## Тесты

    ctest --test-dir Task2/build --output-on-failure

## Стандарт языка

C++17.
